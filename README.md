# Antirules

Antirules is a anti-virus where you can set rules for every application.

> [!WARNING]
> Right now, Antirules should NOT be used as a antivirus!
> 
> To block a program, it **HAS** to be fully running for it to block it.
> I will fix this, but right now this is just a early test.
>
> And again, **DO NOT USE THIS AS A ANTIVIRUS RIGHT NOW**

# Features

## Rulesets

You can easily create rulesets for how files download, what to do when a program runs, what to do when a website loads, etc.

You can also use many methods of finding a file and blocking it/allowing it.

- Process
- Filename
- Path
- Publisher
- Parent Process
- Command Line
- Downloaded From
- Download URL
- Downloaded Via
- SHA256
- Folder
- Extension
- Signature
- Service
- Window Title

## Websites

Using rulesets, you can also block websites based on a criteria and choose why they were blocked.
